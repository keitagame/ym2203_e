# ym2203

Rust製のYamaha **YM2203 (OPN)** サウンドチップ・エミュレーターです。外部クレート依存なしのコアで、以下をすべて実装しています。

- FM音源: 3チャンネル × 4オペレータ、アルゴリズム0〜7、セルフフィードバック
- SSG (AY-3-8910互換PSG): 3チャンネルの矩形波 + ノイズ + ハードウェアエンベロープ (16波形)
- タイマーA/B、ステータスレジスタ、割り込みフラグ
- チャンネル3スペシャルモード(4オペレータ独立周波数)、CSMモード
- SSG-EG(FMオペレータのAY風ループエンベロープ)
- プリスケーラ(÷2 / ÷3 / ÷6)

## 使い方

```rust
use ym2203::Ym2203;

let mut chip = Ym2203::new(3_993_600, 44_100); // (chip clock Hz, output sample rate Hz)

// ch0 オペレータS1 (アドレス 0x30 系列)
chip.write(0x30, 0x01); // DT=0, MUL=1
chip.write(0x40, 0x00); // TL=0 (最大音量)
chip.write(0x50, 0x1F); // KS=0, AR=31(最速アタック)
chip.write(0x80, 0x0F); // SL=0, RR=15

chip.write(0xB0, 0x07); // ch0: アルゴリズム7(全並列), フィードバック0

chip.write(0xA4, 0x22); // ch0: F-Number上位/ブロック
chip.write(0xA0, 0x69); // ch0: F-Number下位  (A4=440Hz相当)

chip.write(0x28, 0xF0); // ch0 キーオン(全スロット)

let pcm: Vec<i16> = chip.generate(44_100); // 1秒分のモノラル16bit PCM
```

`cargo run --release --example demo` でFMリード + ベース + SSGハイハットのデモを`demo_output.wav`に書き出せます。
`cargo run --release --example freqtest` は440Hzの単音テストをFM/SSGそれぞれ書き出し、ピッチ精度を検証できます(FFTで実測441.4Hz、分解能誤差内でほぼ一致)。

## レジスタマップ(実装済み)

| アドレス | 内容 |
|---|---|
| 0x00-0x0D | SSG (AY-3-8910互換): トーン周期A/B/C, ノイズ周期, ミキサー, 音量A/B/C, エンベロープ周期, エンベロープ形状 |
| 0x24-0x25 | タイマーA (10bit) |
| 0x26 | タイマーB (8bit) |
| 0x27 | タイマースタート/割り込み許可/リセット, CSM/3chスペシャルモード選択 |
| 0x28 | キーオン/オフ (bit0-1=ch, bit4-7=スロットマスク) |
| 0x2D/0x2E/0x2F | プリスケーラ選択 (÷2 / ÷3 / ÷6) |
| 0x30-0x3F | DT/MUL (オペレータ毎) |
| 0x40-0x4F | TL (トータルレベル) |
| 0x50-0x5F | KS/AR |
| 0x60-0x6F | AM(無視)/D1R |
| 0x70-0x7F | D2R |
| 0x80-0x8F | D1L(SL)/RR |
| 0x90-0x9F | SSG-EG |
| 0xA0-0xA2 | F-Number下位 (ch0-2) |
| 0xA4-0xA6 | F-Number上位/ブロック (ch0-2) |
| 0xA8-0xAA | ch3スペシャルモード用 F-Number下位 (S1/S2/S3) |
| 0xAC-0xAE | ch3スペシャルモード用 F-Number上位/ブロック (S1/S2/S3) |
| 0xB0-0xB2 | フィードバック/アルゴリズム |

オペレータのレジスタアドレスは実チップと同じ「1,3,2,4」物理配置(0x30-0x33=S1, 0x34-0x37=S3, 0x38-0x3B=S2, 0x3C-0x3F=S4、各グループ内のオフセット0-2がch0-2)を再現しています。

## 精度についての設計方針(重要)

このエミュレーターは**レジスタレベルでは完全**です。実チップの全機能・全レジスタが意味を持ち、音程(周波数)は実チップと同じF-Number/Block公式 `f = fnum * clock * 2^block / (144 * 2^20)` からビット単位で正確に計算されるため、実機の音楽ドライバのレジスタダンプをそのまま流しても正しい音階になります。

一方で、**エンベロープジェネレータの内部タイミングはビット精度の再現ではなく、キャリブレーションされた指数関数近似です**。実チップ(YM2203)のアタック/ディケイ/サステイン/リリースは、内部の固定小数点カウンタと256/512エントリのレート選択テーブル(いわゆる `eg_rate_shift` / `eg_rate_select` / `eg_inc` テーブル)によって生成される、非常に特徴的な階段状の増分パターンを持っています。これを1bitも違わず再現するには、そのテーブル群をリバースエンジニアリング資料通りに寸分違わず書き写す必要があり、記憶からの再現には誤りのリスクが伴います。そのため本実装では、

- レート値(0-63、KSによるレートスケーリング込み)を、
- 攻撃(アタック)は乗算的指数近似、減衰/サステイン/リリースはdBドメイン線形(=振幅ドメイン指数関数的減衰)

という、実チップと同じ「形」のカーブになるよう調整した式に変換しています。同様に、SSG(AY-3-8910互換)部分のトーン/ノイズ/エンベロープは、実チップの分周比(トーン: clock/(16×period)、ノイズも同様)をそのまま使った位相アキュムレータで実装しており、周波数はビット精度で正確です。音量テーブルのみ実測ではなく対数近似式を使っています。

まとめると:
- **正確**: レジスタマップ全体、FM/SSGの音程・周波数、アルゴリズム結線、キーオン/オフ挙動、タイマー周期の式、SSGエンベロープ形状のステートマシン
- **近似**: FMエンベロープの秒単位の正確な時間特性、SSG音量テーブルの正確なdB値、DT(デチューン)の正確なセント量、SSG-EGの詳細な波形

Nuked-OPN2やymfmのようなサイクル精度/ビット精度のコアが必要な場合(実機との波形比較、レジスタトレースの完全一致検証など)は、本実装ではなくそれらの利用を推奨します。本実装は「レジスタを叩けば実機同様に動作し、実機らしい音が鳴る、読みやすい完全実装のRustコード」を目的としています。
